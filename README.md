# 오늘의 쉼 ☕ — 나를 위한 에너지 충전소

지치고 번아웃이 온 날, 매일 마음을 기록하고 → 데이터로 나를 이해하고 → 위로받으며 조금씩 회복하는 셀프케어 웹앱입니다.
설치 없이 브라우저에서 바로 열 수 있고, 홈 화면에 앱처럼 설치해 **오프라인**으로도 쓸 수 있어요.

## 화면 구성 (하단 탭)

### 📔 오늘
- **기분 체크인** — 6가지 기분 중 선택하면 그에 맞는 따뜻한 말을 건네요.
- **에너지 슬라이더** — 오늘 에너지를 1~5칸으로.
- **일기** — 오늘 하루를 한 줄이라도 기록.
- **오늘 잘한 일** — 사소한 자기 칭찬 기록.
- 저장하면 **연속 기록(스트릭)** 을 응원해줘요.

### 🌿 쉼
- **나를 위한 한마디** — 응원 문구 랜덤.
- **호흡 쉼표** — 4·7·8 호흡 애니메이션 + 가이드 사운드.
- **아주 작은 한 걸음** — 부담 없는 미션 추천.
- **잔잔한 배경음** — 🌧️ 빗소리 / 🌊 파도 / 🌲 숲·새소리 / 🔥 모닥불.
  - 음원 파일 없이 **Web Audio로 실시간 합성**: 빗방울·장작 탁탁임·새 지저귐 같은 디테일을
    무작위로 만들고, 잔향(리버브)으로 공간감을 더했어요. 오프라인에서도 그대로 동작.

### 🎯 챌린지 (90일 습관 만들기 · 복수 등록)
- 3달이면 습관이 된다는 점에 착안한 **90일 습관 트래커**. **여러 습관을 동시에** 등록·관리.
- 카드 한 장당 1탭으로 오늘 완료 체크, 펼치면 **90칸 잔디 그리드**.
- **실행의도(Implementation Intentions, Gollwitzer)**: "나는 [언제]에 [습관]을 한다" 문장으로 설계.
- **습관 쌓기(Habit Stacking, Fogg)**: 기존 행동(기상 후·양치 후 등)에 새 습관을 붙이는 트리거 선택.
- **2분 규칙 최소 버전**: 컨디션 낮은 날을 위한 작은 대안 기록.
- **비처벌 설계(Lally 2010)**: 빠진 날을 빨간 X가 아니라 회색 칸으로 — 한두 번 쉬어도 습관은 사라지지 않아요.
- **마일스톤 축하** — 1·3·7·21·30·66·90일 도달 시 메시지 + 사운드 + 컨페티 🎉
- 🔌 **캘린더(.ics) 연동** — 습관별로 구글/애플 캘린더에 90일치 매일 알림 추가.
- 🔌 **공유** — Web Share API로 진행 상황 공유 (미지원 시 클립보드 복사).

## 🧠 심리학 근거 (전문 자문 반영)

이 앱의 위로 문구·인사이트·습관 설계는 검증된 심리학 연구에 기반합니다.

- **자기자비(Self-Compassion)** — Neff (2003): 자기비판 대신 따뜻한 타당화 톤.
- **행동활성화(Behavioral Activation)** — Martell et al. (2010): "기분이 나아지길 기다리기보다 작은 행동 먼저".
- **습관형성** — Lally et al. (2010): 자동화 평균 66일·범위 18–254일, 1회 누락은 무영향 → 비처벌 설계.
- **실행의도** — Gollwitzer (1999): if-then 계획이 실천율을 높임.
- **정서 명명(Affect Labeling)** — Lieberman et al. (2007): 감정에 이름 붙이기가 편도체 활동을 낮춤 → 일기/기분 태깅.
- **자기결정이론(SDT)** — Deci & Ryan: 자율성·유능감·관계성. 강요·죄책감 대신 스스로 선택.
- **감사** — Emmons & McCullough (2003): 구체적 감사 3가지의 안녕감 효과.

**기록 탭 인사이트**는 위 이론을 if-then 규칙으로 구현했어요. 예: 최근 3일 기분이 낮으면 행동활성화를 권하고,
일기에서 위기 신호가 감지되면 **안전 카드**(상담 전화)를 최우선으로 띄웁니다.

> ⚠️ 이 앱은 셀프케어 보조 도구이며 진단·치료를 대신하지 않아요. 위기 시 자살예방상담 **109**(24시간).

## 사용 방법

`index.html` 을 브라우저로 열면 끝이에요. 또는 로컬 서버로:

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

휴대폰 브라우저에서 "홈 화면에 추가"를 누르면 앱처럼 쓸 수 있어요.

## 개인정보

모든 기록(일기·기분·에너지·칭찬)은 **사용자 기기(localStorage)에만** 저장됩니다.
서버 전송이나 외부 공유가 전혀 없어요. 백업이 필요하면 설정에서 직접 내보낼 수 있어요.
