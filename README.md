# 오늘의 쉼 ☕ — 나를 위한 에너지 충전소

지치고 번아웃이 온 날, 매일 마음을 기록하고 → 데이터로 나를 이해하고 → 위로받으며 조금씩 회복하는 셀프케어 웹앱입니다.
설치 없이 브라우저에서 바로 열 수 있고, 홈 화면에 앱처럼 설치해 **오프라인**으로도 쓸 수 있어요.

## 화면 구성 (하단 탭)

### 💛 정서 케어
- **기분 7단계** — 우울/무기력/지침/불안/그럭저럭/괜찮음/활기참.
- **저녁 회고** — "오늘 가장 좋았던 / 힘들었던 순간" 2문항 (선택, 구조화 일기).
- **위로 문구 즐겨찾기 + 내 문구 추가** — 와닿는 말을 모으고 직접 써넣기. ("즐겨찾기만 보기")

### ✨ 오늘의 여정 (적응형 기록 경로)
한 번에 하나씩 따라가며 매끄럽게 하루를 기록하는 풀스크린 흐름. **오늘의 기록 + 습관까지 한 경로에**.
- 기분 → 에너지 → (기분이 무거우면) 숨 고르기 → 한 줄 일기 → 감정 태그 → 잘한 일 → (습관 있으면) 습관 체크 → (저녁이면) 회고 → 마무리
- **기분·시간대·습관 유무에 따라 경로가 분기**되고 질문 문구도 달라져요. 진행 바로 끝이 보여요.
- 오늘 탭은 '여정'이 기본, 상세 폼은 접어두어 **한 화면에서 시작**할 수 있어요.

### 🌬️ 호흡 사운드 (스파 세션)
4·7·8 호흡에 **따뜻한 드론 화음 + 숨처럼 열리고 닫히는 필터 노이즈 + 단계마다 싱잉볼** 울림.
삑삑이는 톤이 아니라 몰입형 사운드 세션이에요. 🌙 수면 모드와도 어울려요.

### 📔 오늘
- **기분 체크인** — 6가지 기분 중 선택하면 그에 맞는 따뜻한 말을 건네요.
- **에너지 슬라이더** — 오늘 에너지를 1~5칸으로.
- **일기** — 오늘 하루를 한 줄이라도 기록.
- **오늘 잘한 일** — 사소한 자기 칭찬 기록.
- **🎯 오늘의 습관** — 등록한 습관을 메인 화면에서 바로 보고, 동그라미를 눌러 **오늘 완료를 한 번에 체크**. 진행률·연속(🔥)에 더해 **습관 분석 인사이트 한 줄**(기분 연관·요즘 흐름·가장 꾸준한 습관)까지 보여줘요. (이름을 누르면 습관 상세로)
- 저장하면 **연속 기록(스트릭)** 을 응원해줘요.

### 🌿 쉼
- **나를 위한 한마디** — 응원 문구 랜덤.
- **호흡 쉼표** — 4·7·8 호흡 애니메이션 + 부드러운 저음 가이드 사운드. 매 초 카운트.
- **🌙 수면 모드** (빠른 호흡 ▶ 토글) — 화면을 어둡게, 카운트음 끄고 잔잔한 패드+빗소리, 12회 후 자동 페이드아웃. 화면 꺼짐 방지(Wake Lock)로 소리가 끊기지 않아요.
- **아주 작은 한 걸음** — 부담 없는 미션 추천.
- **🆘 많이 힘들 땐** — 위기 상담 전화(109·1577-0199·119)를 **항상** 볼 수 있는 카드. 번호를 누르면 바로 연결돼요.
- **잔잔한 배경음** — 🌧️ 빗소리 / 🌊 파도 / 🌲 숲·새소리 / 🔥 모닥불.
  - 음원 파일 없이 **Web Audio로 실시간 합성**: 빗방울·장작 탁탁임·새 지저귐 같은 디테일을
    무작위로 만들고, 잔향(리버브)으로 공간감을 더했어요. 오프라인에서도 그대로 동작.

### 🎯 챌린지 (90일 습관 만들기 · 복수 등록)
- 3달이면 습관이 된다는 점에 착안한 **90일 습관 트래커**. **여러 습관을 동시에** 등록·관리.
- 카드 한 장당 1탭으로 오늘 완료 체크, 펼치면 **90칸 잔디 그리드**.
- **실행의도(Implementation Intentions, Gollwitzer)**: "나는 [언제]에 [습관]을 한다" 문장으로 설계.
- **습관 쌓기(Habit Stacking, Fogg)**: 기존 행동(기상 후·양치 후 등)에 새 습관을 붙이는 트리거 선택.
- **2분 규칙 최소 버전**: 컨디션 낮은 날을 위한 작은 대안 기록.
- **비처벌 설계(Lally 2010)**: 빠진 날을 빨간 X가 아니라 회색 칸으로 — 한두 번 쉬어도 습관은 사라지지 않아요.
- **마일스톤 축하** — 1·3·7·21·30·66·90일 도달 시 메시지 + 사운드 + 컨페티 🎉
- 🔌 **캘린더(.ics) 연동** — 습관별로 구글/애플 캘린더에 90일치 매일 알림 추가.
- 🔌 **공유** — Web Share API로 진행 상황 공유 (미지원 시 클립보드 복사).

## 🧠 심리학 근거 (전문 자문 반영)

이 앱의 위로 문구·인사이트·습관 설계는 검증된 심리학 연구에 기반합니다.

- **자기자비(Self-Compassion)** — Neff (2003): 자기비판 대신 따뜻한 타당화 톤.
- **행동활성화(Behavioral Activation)** — Martell et al. (2010): "기분이 나아지길 기다리기보다 작은 행동 먼저".
- **습관형성** — Lally et al. (2010): 자동화 평균 66일·범위 18–254일, 1회 누락은 무영향 → 비처벌 설계.
- **실행의도** — Gollwitzer (1999): if-then 계획이 실천율을 높임.
- **정서 명명(Affect Labeling)** — Lieberman et al. (2007): 감정에 이름 붙이기가 편도체 활동을 낮춤 → 일기/기분 태깅.
- **자기결정이론(SDT)** — Deci & Ryan: 자율성·유능감·관계성. 강요·죄책감 대신 스스로 선택.
- **감사** — Emmons & McCullough (2003): 구체적 감사 3가지의 안녕감 효과.

**기록 탭 인사이트**는 위 이론을 if-then 규칙으로 구현했어요. 예: 최근 3일 기분이 낮으면 행동활성화를 권하고,
일기에서 위기 신호가 감지되면 **안전 카드**(상담 전화)를 최우선으로 띄웁니다.

> ⚠️ 이 앱은 셀프케어 보조 도구이며 진단·치료를 대신하지 않아요. 위기 시 자살예방상담 **109**(24시간).

## ☁️ 클라우드 동기화 & 로그인 & 커뮤니티 (선택)

설정하면 **여러 기기에서 같은 계정으로 로그인**해 기록이 자동 동기화되고, **함께 탭 커뮤니티**(공개 방·명단·방장 시작/종료)가 살아나요. 설정 전에는 기존처럼 이 기기에만 저장됩니다(완전 동작).

백엔드는 무료로 시작 가능한 **Firebase**를 사용합니다 (iOS·Android·웹 공통).

**1) 프로젝트 만들기**
[console.firebase.google.com](https://console.firebase.google.com) → 프로젝트 추가 → 프로젝트 설정(⚙) → 일반 → "웹 앱 추가(</>)".

**2) `config.js`에 설정 붙여넣기**
웹 앱 등록 화면의 `firebaseConfig` 값을 그대로:
```js
window.ONEUL_CONFIG = {
  FIREBASE: {
    apiKey: "AIzaSy...",
    authDomain: "oneul-shim.firebaseapp.com",
    projectId: "oneul-shim",
    databaseURL: "https://oneul-shim-default-rtdb.asia-southeast1.firebasedatabase.app",
    appId: "1:1234567890:web:abcdef",
  },
};
```
> `apiKey`는 공개되어도 안전한 식별자예요. 접근 제어는 아래 보안 규칙이 담당합니다.
> `databaseURL`은 **Realtime Database**(명단·실시간 인원·방장 제어용)를 만들면 생겨요.

**3) 로그인 방법 켜기**
Authentication → Sign-in method → **이메일/비밀번호** 사용 설정 (+원하면 **Google**).

**4) Firestore 만들기 + 보안 규칙** (기록 동기화 + 공개 방 목록)
Firestore Database → 데이터베이스 만들기 → 규칙 탭에 붙여넣기:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 내 기록: 본인만 읽고 쓸 수 있음
    match /app_state/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    // 함께 탭 공개 방: 읽기는 누구나, 만들기·수정·삭제는 로그인한 본인 방만
    match /rooms/{roomId} {
      allow read: if true;
      allow create, update: if request.auth != null
        && request.resource.data.owner == request.auth.uid
        && request.resource.data.name is string && request.resource.data.name.size() <= 14
        && request.resource.data.mood is string && request.resource.data.mood.size() <= 24;
      allow delete: if request.auth != null && resource.data.owner == request.auth.uid;
    }
  }
}
```

**5) Realtime Database 만들기 + 보안 규칙** (명단·실시간 인원·방장 시작/종료)
Realtime Database → 데이터베이스 만들기 → 규칙 탭에 붙여넣기:
```json
{
  "rules": {
    "presence": { "breathe": {
      ".read": true,
      "$key": { ".write": true,
        ".validate": "newData.hasChild('at') && (!newData.child('name').exists() || newData.child('name').val().length <= 12)" }
    }},
    "rooms_live": {
      "$roomId": { ".read": true, ".write": "auth != null" }
    }
  }
}
```
> presence는 익명·일시적 존재 표시(방·닉네임·시각)만 담고, 연결이 끊기면 자동 삭제(onDisconnect)돼요. 방 시작/종료는 로그인해야 쓸 수 있어요.

**6) 사용**
설정 탭 → ☁️ 계정 & 동기화 에서 로그인. 이후 기록 변경 시 자동 저장되고, 다른 기기에서 로그인하면 **병합**돼요(일기는 수정 시각 기준 최신 우선, 습관 완료는 **날짜별 토글 시각 기준 최신** — 한쪽의 '완료 해제'가 다른 기기의 옛 완료에 덮이지 않아요). 함께 탭에서는 로그인한 사용자가 방을 만들면 모두의 목록에 뜨고, 로비에 **명단**이 보이며 **방장이 시작·종료**를 제어해요.

> 동작 방식: 변경 시 원격을 먼저 받아 **병합 후 업로드**(blind overwrite 방지)해서 다른 기기의 편집이 사라지지 않아요. **삭제는 묘비(tombstone)로 전파**돼 지운 기록이 다른 기기에서 되살아나지 않습니다. 실시간 양방향 푸시는 아니므로, 다른 기기 변경은 그 기기에서 "지금 동기화"나 재로그인 시 반영돼요.

## 개인정보

기본적으로 모든 기록은 **사용자 기기(localStorage)에만** 저장돼요. 클라우드 동기화를 **직접 설정해 로그인한 경우에만**, 본인 계정의 Firebase에 전송되어 저장됩니다(보안 규칙으로 본인만 접근). 동기화를 켜지 않으면 외부 전송이 전혀 없어요.
