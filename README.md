# 오늘의 쉼 ☕ — 나를 위한 에너지 충전소

지치고 번아웃이 온 날, 잠깐 숨 고르고 스스로를 위로할 수 있는 작은 웹앱입니다.
설치 없이 브라우저에서 바로 열어 쓸 수 있어요. 휴대폰·PC 모두 동작합니다.

## 기능

- 🌤️ **기분 체크인** — 지금 마음 상태를 고르면 그에 맞는 따뜻한 말을 건네요.
- 💌 **나를 위한 한마디** — 버튼을 누르면 응원 문구가 랜덤으로 나와요.
- 🌬️ **호흡 쉼표** — 4·7·8 호흡 애니메이션을 따라 마음을 진정시켜요.
- ✨ **아주 작은 한 걸음** — 부담 없는 작은 미션을 추천해요.
- 🌱 **오늘 잘한 일** — 사소한 칭찬을 기록하고 모아볼 수 있어요.

## 사용 방법

`index.html` 파일을 더블 클릭해서 브라우저로 열기만 하면 됩니다.

또는 간단한 로컬 서버로 띄울 수도 있어요:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 개인정보

기분·칭찬 기록은 모두 **사용자 기기(localStorage)에만** 저장됩니다.
서버로 전송되거나 외부에 공유되지 않아요. 안심하고 쓰세요.
