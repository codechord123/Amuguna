# 오늘의 쉼 — 제품 로드맵 & 수익화 기획

> 핵심 원칙: **로컬 우선(local-first)**. 기록은 기본적으로 기기에만 저장 → 개인정보 안전 + 출시 쉬움.
> 계정·클라우드·수익화는 *필요한 단계에서만* 얹는다.

## 1. 테스트 단계 (P1~P3) — 계정·DB **불필요**

목적은 "아이폰에서 잘 도는가" 확인. 사용자 데이터는 기기 저장만.

- **P1 — iOS 래핑 & 로컬 실행**
  - `npx cap add ios` → `cap sync` → Xcode 시뮬레이터 ▶︎
  - 기기 저장 모드로 모든 기능 점검(여정·기록·분석·달력·리포트)
- **P2 — 고급 네이티브 기능**
  - `@capacitor/haptics`(진동), `local-notifications`(리마인더), `status-bar`/`splash-screen`(디자인)
  - 사운드: 앰비언트 음원 파일(`./sounds/`) + 알림 차임, (선택)백그라운드 재생
  - 앱 아이콘/스플래시 자동 생성(`@capacitor/assets`)
- **P3 — TestFlight 클로즈드 베타**
  - Apple Developer 가입($99) 후 Archive→Upload
  - 가족·지인 초대해 실사용 피드백 (심사 전 단계, 가벼움)

➡ 여기까진 **회원가입/DB 0**. 로그인 화면도 안 띄움.

## 2. 정식 출시 (P4) — 무료, 로컬 우선

- 기능 전체 무료 공개(기기 저장). 백업은 **'내보내기(파일)'** 로.
- 계정은 **아직 선택/없음** → 심사 단순, 개인정보 라벨 유리.
- 심사 필수: 개인정보 처리방침 URL(있음), "의학적 진단 아님" 명시(있음), 스크린샷·설명.

> 권장: 1차는 **계정 없이** 빠르게 출시 → 사용자 반응 확인 후 P5/P6.

## 3. 수익화 기획 (P5) — 회원가입 **없이도 가능**

### 3-1. 모델 비교 (정신건강 앱 기준)
| 모델 | 설명 | 적합도 |
|---|---|---|
| **프리미엄 구독** | 무료 핵심 + 유료 고급 | ⭐⭐⭐ 추천 |
| 평생 1회 결제(Lifetime) | 한 번 사면 영구 | ⭐⭐ 보조 옵션 |
| 광고 | 배너/전면 광고 | ❌ 신뢰·정서 해침, 비추 |
| 후원(Tip) | 자발적 후원 | ⭐ 부가 |

➡ **프리미엄 구독(+ 평생결제 옵션)** 추천. 광고는 넣지 않음(브랜드 가치).

### 3-2. 무료 vs 프리미엄 경계 (핵심 무료 유지)
> 애플 심사·윤리상 **핵심 기능은 무료**여야 함. 프리미엄은 '더 깊게/예쁘게'.

- **무료(영구):** 매일 기록, 기분 점수·감정, 호흡, 기본 분석, 달력, 주간 리포트
- **프리미엄 후보:**
  - 심화 분석(감정 지도·생각의 지도 무제한, 장기 추이)
  - 프리미엄 사운드(실제 녹음 앰비언트, 백그라운드 재생)
  - 고급 애니메이션(Lottie)·테마·앱 아이콘
  - 클라우드 동기화/백업(= P6)
  - 홈 화면 위젯, (향후)AI 코멘트

### 3-3. 가격(예시, 무료체험 7일)
- 월 ₩3,900 · 연 ₩29,000(월 환산 ↓) · 평생 ₩49,000

### 3-4. 도구 & 수수료
- **RevenueCat**(추천): 구독·결제·복원·영수증 관리. 월 매출 $2.5k까지 무료. **회원가입 없이 익명ID로 동작.**
- 또는 순수 **StoreKit 2** 직접.
- 애플 수수료: 30% (단, **Small Business Program 가입 시 연매출 $1M 미만은 15%**).

### 3-5. 수익화에 필요한 것
- 🤖 결제 화면(페이월) UI + 엔타이틀먼트 분기 코드
- 🍎 Xcode에서 In-App Purchase 설정
- 👤 App Store Connect에 상품(구독) 등록 + Small Business Program 신청
- 규정: 구독은 **복원(Restore) 버튼**·약관·취소 안내 필수

## 4. 회원가입 & DB (P6) — 기기 간 동기화가 필요해질 때

**언제 필요?** "폰 바꿔도 기록 유지", "여러 기기 동기화"를 원할 때. (수익화엔 불필요)

- **Supabase**(무료 시작): 인증 + Postgres + RLS(본인 데이터만 접근). anon키 공개 안전.
- 이미 `cloud.js`에 로그인·병합 로직 골격 있음. config에 키만 넣으면 켜짐.
- **애플 규정(계정 도입 시 필수):**
  - **앱 내 계정 삭제** 기능(데이터 포함) — 규정 5.1.1(v)
  - 소셜 로그인 넣으면 **Sign in with Apple** 동반 — 규정 4.8 (이메일/비번만이면 면제)
  - 개인정보 처리방침에 수집 항목 명시
- DB 관리: 대시보드에서 백업·사용량 모니터링, 무료 한도(DB 500MB·MAU 5만)로 시작.

## 5. 추천 진행 순서 (요약)

1. **P1~P3**: 계정·DB·수익화 전부 끄고 **테스트만** (지금 바로 사전정비 가능)
2. **P4**: 무료로 정식 출시 (로컬 우선, 계정 없음) → 반응 확인
3. **P5**: 구독 수익화 도입 (회원가입 불필요, RevenueCat)
4. **P6**: 클라우드 계정/동기화 (이때 회원가입+DB+계정삭제 규정)
5. **P7**: 위젯·HealthKit·AI 고도화

> 이렇게 가면 **테스트는 가볍게, 출시는 빠르게, 수익화는 계정 부담 없이, 동기화는 나중에** — 위험과 비용을 단계마다 최소화.

## 7. 키워드 엔진(생각의 지도) — 사전 보강 계획

생각의 지도(TextRank·Louvain·키워드 추출)는 **풍부한 한국어 사전**이 받쳐줘야 제대로 산다.
하지만 브라우저(웹뷰)는 형태소 분석기를 못 돌려, 현재는 경량 휴리스틱(불용어·의존명사 제거,
과거형 원형화, 핵심 1글자 명사/동사 화이트리스트)으로 근사한다. 한계: 화이트리스트에 없는
단어는 누락될 수 있음(예: 드문 1글자 명사/동사).

**결정(채택): 웹은 현 휴리스틱 유지 → iOS 네이티브 단계(P7)에서 Apple NLTagger로 교체.**
- `NaturalLanguage` 프레임워크의 **NLTagger(.lexicalClass / .lemma)** 로 한국어 품사 태깅·원형화.
- **무료·OS 내장·용량 0**, 정확도 높음 → 손으로 관리하던 화이트리스트를 통째로 대체.
- Capacitor 커스텀 플러그인으로 브리지: JS가 텍스트를 넘기면 네이티브가 명사/동사 원형 배열 반환.
- 폴백: 네이티브 미가용(웹/안드로이드)일 땐 기존 휴리스틱 사용.

대안(미채택, 필요 시 재검토): 한국어 사전 번들(웹, 수십~수백KB), Kiwi WASM 형태소분석(웹, 수 MB 지연로드).

**콜드스타트(사용자 데이터 양):** 알고리즘은 기록이 쌓일수록 풍부해진다. 적을 땐 임계값 가드로
간단히 보여주고, 리텐션(연속·리마인더·미션)으로 데이터가 쌓이며 자연히 또렷해지는 구조.
